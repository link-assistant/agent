# Backward-compatibility audit: PR for issue #335

Scope: `git diff origin/main...HEAD -- js/src rust/src` (branch `issue-335-cc63abda9307`).
Line numbers refer to the PR branch. Each claim was checked against the full file, not only the diff hunk.

## What is NOT changed

- CLI surface: no changes in `js/src/cli`, `js/src/index.js`, `rust/src/cli.rs` or `js/src/config/*`. Flags, the JSON input format (stdin/`--prompt`) and the env-var config are unchanged.
- JSON event envelope: no change to the event types or field layout in stdout. Changes appear only *inside* existing fields: error `name`/`data`, tool `state.output`/`metadata`, and `tokens`.
- Stored session schema: only widened (new union members, new optional metadata keys). **Old stored sessions still load.** Sessions written by the new version may not load in an old binary (see S1).

## Legend

- Category: JSON-output, JSON-input, tool-schema, tool-output-text, semantics, storage.
- Risk:
  - high: likely to break existing users or scripts;
  - medium: plausible breakage for some setups;
  - low: cosmetic, or only affects edge cases;
  - none: pure fix or relaxation.
- Mechanism: suggested opt-out. Env vars follow the existing `LINK_ASSISTANT_AGENT_*` pattern in `js/src/config/config.ts`. Rust should mirror them via `rust/src/cli.rs` (lino-arguments) or the same env var.
